# Sounds

These are silent placeholder files. Replace any of them with a real `.wav` (or edit `src/audio.ts` to point at `.mp3`/`.ogg`) and the game will play it. Keep the file names.

| File          | Played when                                      |
| ------------- | ------------------------------------------------ |
| deal.wav      | cards are dealt                                  |
| your-turn.wav | it becomes your turn                             |
| play.wav      | any player plays a combination                   |
| pass.wav      | a player passes                                  |
| bomb.wav      | a bomb is played                                 |
| rocket.wav    | a rocket is played                               |
| landlord.wav  | the landlord is chosen and the kitty is revealed |
| win.wav       | your side wins the hand                          |
| lose.wav      | your side loses the hand                         |
| spring.wav    | a spring or anti-spring is scored                |
| chat.wav      | a chat message or emote arrives                  |
| tick.wav      | the turn timer is about to run out               |
